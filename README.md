# kkd-1093.github.io

KKD App Studio(개인 개발자)의 대표 웹사이트다. 주소: https://kkd-1093.github.io/

- 첫 화면(`index.html`): 앱 목록과 연락처. 스토어의 "개발자 웹사이트"에 이 주소를 적는다.
- `app-ads.txt`: 이 개발자의 앱 광고를 팔 수 있는 곳(AdMob 계정)을 밝힌다. 광고 업계 표준(IAB)이라 도메인 맨 위에 있어야 한다. 모든 앱이 함께 쓴다.
- 앱마다 소개와 개인정보 처리방침은 각 앱의 저장소(예: `kkd-1093/buddy-site` → `/buddy-site/`)에 둔다.

## 규칙

- 빌드 없이 HTML을 그대로 올린다(`.nojekyll`).
- 작업마다 브랜치 → PR → merge commit으로 합친다. 커밋 메시지는 한국어로 쓴다.
- 사이트 주소, 저장소 이름, 계정 이름에 "tft" 등 게임 상표를 넣지 않는다(Riot 상표 규칙). 앱 이름 "TFT Buddy"를 앱 소개에 쓰는 것은 괜찮다.
- 광고 계정을 바꾸거나 광고 네트워크를 더하면 `app-ads.txt`를 함께 고친다.
- 나중에 도메인을 사면 이 저장소에 연결한다. GitHub이 옛 주소(`kkd-1093.github.io/...`)를 새 도메인으로 넘겨 준다.
